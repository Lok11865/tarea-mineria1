Minería de Datos con AdventureWorks2022

10 ejemplos prácticos usando SQL Server para descubrir patrones, tendencias y conocimiento útil en los datos.

¿Qué es la Minería de Datos?

La minería de datos es el proceso de analizar grandes cantidades de información para encontrar patrones, relaciones, tendencias y comportamientos que ayuden a tomar mejores decisiones. En una empresa, puede servir para analizar ventas, clientes, productos, territorios, inventario, compras y rendimiento del negocio.

En este blog se usa la base de datos AdventureWorks2022, una base de datos de ejemplo de Microsoft SQL Server que simula una empresa comercial.

1. Productos más vendidos

Objetivo

Identificar los productos con mayor cantidad vendida para conocer cuáles generan más movimiento comercial.

USE AdventureWorks2022;
GO

SELECT TOP 10
    p.Name AS Producto,
    SUM(sod.OrderQty) AS CantidadVendida,
    SUM(sod.LineTotal) AS TotalVendido
FROM Sales.SalesOrderDetail sod
INNER JOIN Production.Product p
    ON sod.ProductID = p.ProductID
GROUP BY p.Name
ORDER BY CantidadVendida DESC;

2. Clientes con mayores compras

Objetivo

Detectar los clientes que más compran para ofrecer promociones, descuentos o atención personalizada.

USE AdventureWorks2022;
GO

SELECT TOP 10
    c.CustomerID,
    CONCAT(p.FirstName, ' ', p.LastName) AS Cliente,
    SUM(soh.TotalDue) AS TotalComprado
FROM Sales.Customer c
INNER JOIN Sales.SalesOrderHeader soh
    ON c.CustomerID = soh.CustomerID
LEFT JOIN Person.Person p
    ON c.PersonID = p.BusinessEntityID
GROUP BY c.CustomerID, p.FirstName, p.LastName
ORDER BY TotalComprado DESC;

3. Ventas por territorio

Objetivo

Analizar qué regiones o territorios generan más ingresos para mejorar la estrategia comercial.

USE AdventureWorks2022;
GO

SELECT
    st.Name AS Territorio,
    st.CountryRegionCode AS Pais,
    SUM(soh.TotalDue) AS TotalVentas
FROM Sales.SalesOrderHeader soh
INNER JOIN Sales.SalesTerritory st
    ON soh.TerritoryID = st.TerritoryID
GROUP BY st.Name, st.CountryRegionCode
ORDER BY TotalVentas DESC;

4. Ventas por año y mes

Objetivo

Encontrar tendencias de ventas a través del tiempo para identificar temporadas altas o bajas.

USE AdventureWorks2022;
GO

SELECT
    YEAR(OrderDate) AS Anio,
    MONTH(OrderDate) AS Mes,
    COUNT(SalesOrderID) AS NumeroOrdenes,
    SUM(TotalDue) AS TotalVentas
FROM Sales.SalesOrderHeader
GROUP BY YEAR(OrderDate), MONTH(OrderDate)
ORDER BY Anio, Mes;

5. Categorías de productos más rentables

Objetivo

Conocer qué categorías generan mayores ingresos para priorizar inventario y campañas.

USE AdventureWorks2022;
GO

SELECT
    pc.Name AS Categoria,
    SUM(sod.LineTotal) AS TotalVentas
FROM Sales.SalesOrderDetail sod
INNER JOIN Production.Product p
    ON sod.ProductID = p.ProductID
INNER JOIN Production.ProductSubcategory ps
    ON p.ProductSubcategoryID = ps.ProductSubcategoryID
INNER JOIN Production.ProductCategory pc
    ON ps.ProductCategoryID = pc.ProductCategoryID
GROUP BY pc.Name
ORDER BY TotalVentas DESC;

6. Promedio de compra por cliente

Objetivo

Calcular cuánto compra en promedio cada cliente para segmentarlos por valor comercial.

USE AdventureWorks2022;
GO

SELECT TOP 20
    CustomerID,
    COUNT(SalesOrderID) AS NumeroCompras,
    AVG(TotalDue) AS PromedioCompra,
    SUM(TotalDue) AS TotalComprado
FROM Sales.SalesOrderHeader
GROUP BY CustomerID
HAVING COUNT(SalesOrderID) > 1
ORDER BY PromedioCompra DESC;

7. Productos comprados juntos

Objetivo

Detectar productos que aparecen en la misma orden para crear combos o recomendaciones.

USE AdventureWorks2022;
GO

SELECT TOP 20
    p1.Name AS Producto1,
    p2.Name AS Producto2,
    COUNT(*) AS VecesCompradosJuntos
FROM Sales.SalesOrderDetail sod1
INNER JOIN Sales.SalesOrderDetail sod2
    ON sod1.SalesOrderID = sod2.SalesOrderID
   AND sod1.ProductID < sod2.ProductID
INNER JOIN Production.Product p1
    ON sod1.ProductID = p1.ProductID
INNER JOIN Production.Product p2
    ON sod2.ProductID = p2.ProductID
GROUP BY p1.Name, p2.Name
ORDER BY VecesCompradosJuntos DESC;

8. Vendedores con mayor rendimiento

Objetivo

Medir el rendimiento de los vendedores para evaluar resultados y tomar decisiones comerciales.

USE AdventureWorks2022;
GO

SELECT TOP 10
    sp.BusinessEntityID AS IdVendedor,
    CONCAT(p.FirstName, ' ', p.LastName) AS Vendedor,
    SUM(soh.TotalDue) AS TotalVendido
FROM Sales.SalesPerson sp
INNER JOIN Sales.SalesOrderHeader soh
    ON sp.BusinessEntityID = soh.SalesPersonID
INNER JOIN Person.Person p
    ON sp.BusinessEntityID = p.BusinessEntityID
GROUP BY sp.BusinessEntityID, p.FirstName, p.LastName
ORDER BY TotalVendido DESC;

9. Productos con bajo movimiento

Objetivo

Identificar productos con pocas ventas para revisar inventario, precios o estrategias de promoción.

USE AdventureWorks2022;
GO

SELECT TOP 20
    p.ProductID,
    p.Name AS Producto,
    ISNULL(SUM(sod.OrderQty), 0) AS CantidadVendida
FROM Production.Product p
LEFT JOIN Sales.SalesOrderDetail sod
    ON p.ProductID = sod.ProductID
GROUP BY p.ProductID, p.Name
ORDER BY CantidadVendida ASC;

10. Clasificación de clientes por valor

Objetivo

Clasificar clientes como Oro, Plata o Bronce según el total de compras realizadas.

USE AdventureWorks2022;
GO

SELECT
    CustomerID,
    SUM(TotalDue) AS TotalComprado,
    CASE
        WHEN SUM(TotalDue) >= 100000 THEN 'Cliente Oro'
        WHEN SUM(TotalDue) >= 50000 THEN 'Cliente Plata'
        ELSE 'Cliente Bronce'
    END AS SegmentoCliente
FROM Sales.SalesOrderHeader
GROUP BY CustomerID
ORDER BY TotalComprado DESC;

Conclusión

Estos ejemplos muestran cómo la minería de datos permite convertir registros almacenados en información útil. Con AdventureWorks2022 se pueden analizar ventas, clientes, territorios, productos y vendedores para apoyar la toma de decisiones empresariales.
